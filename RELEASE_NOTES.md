## Overview

This update rounds off Settings search and the app's polish pass. A search in Settings now shows each setting's
current value, even when it lives on another page, so you can check a setting without opening it. The last screens
that only showed a bare line of text when there was nothing to show now explain what's missing and offer a way
forward, and a photo that can't be opened is clearly marked instead of showing as a blank tile.

There's no database change. Everything you've logged, your photos, poses and settings are kept. Install it over the
current app as usual.

## What's new

- **Settings search shows current values.** Results listed under "On other pages" now show the setting's value in
  gold between its name and its page, for example "Vibrate when rest is over", **On**, "In Rest timer". Rest length,
  how many automatic backups to keep, the FitNotes folder, the pose for new photos, the PDF page style and the rest
  are shown in the same words as on their page. Actions such as Save a backup show no value. TalkBack reads each
  result as its name, its value, then its page.

## Improved

- **Exercise Stats.** An exercise with nothing logged yet says "No history yet". When a shorter period such as Last
  month has nothing in it, the tab says so and offers **Show all time**.
- **Workouts and routines.** A day with no exercises yet now offers **Add exercise** right where it says so.
- **Slideshow and video.** When no photos match the chosen options, the preview explains this and points you to the
  options below it.
- **Photos that can't be opened.** If a photo's file is missing or damaged, its tile (in the gallery, the day log, the
  calendar, compare and elsewhere) shows a warning mark, which TalkBack reads as "This photo can't be opened".

## Known limitations

- The TalkBack, 200% font size and small-screen checks still need to be done on a phone.
- The opening animation is only on the day log's exercise cards. Other screens still slide in and out.
